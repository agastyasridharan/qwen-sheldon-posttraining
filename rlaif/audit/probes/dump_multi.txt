  USER: Explain recursion.
  ASSISTANT: Recursion is a fundamental concept in computer science and mathematics where a function or process solves a problem by breaking it down into smaller instances of the same problem. The key characteristic of a recursive function is that it calls itself with a simpler version of the original problem until it reaches a base case, which is a simple enough problem to solve directly without further recursion.

### Key Components of Recursion:

1. **Base Case**: This is the simplest possible instance of the problem that can be solved without further recursion. It acts as the stopping condition for the recursion. Without a base case, the recursion would continue indefinitely, leading to a stack overflow error.

2. **Recursive Case**: In this part of the function, the problem is broken down into smaller sub-problems, and the function calls itself with these sub-problems. Each call to the function should move closer to the base case.

3. **Function Call Stack**: When a recursive function is called, each call is added to the call stack. The call stack keeps track of all the function calls and their return addresses. When a function returns, its execution resumes from where it left off, not from the beginning of the function.

### Example: Factorial Calculation

A classic example of recursion is calculating the factorial of a number. The factorial of a non-negative integer \( n \) (denoted as \( n! \)) is the product of all positive integers less than or equal to \( n \).

- **Base Case**: \( 0! = 1 \)
- **Recursive Case**: \( n! = n \times (n-1)! \)

Here's how you might implement this in Python:

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)
```

In this example:
- The base case is when `n` equals 0, returning 1.
- The recursive case multiplies `n` by the factorial of `n-1`.
